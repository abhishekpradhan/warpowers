**War Powers** is a free, browser-playable real-time strategy game in the
spirit of the classic 2000s base-building RTS — built on the GPL-licensed
community engine lineage (GeneralsX → C&C Generals source release) with
**100% original assets and data**. No retail game files are used or required.

- **Play**: (hosted URL at launch)
- **Engine**: our fork of GeneralsX (GPL v3 + EA additional terms), compiled
  natively (SDL3 + DXVK + MoltenVK) and for the browser (Emscripten + WebGL2).
- **Assets**: CC BY 4.0 originals (code MIT) (see LICENSE-ASSETS.md, ASSETS.md,
  CREDITS.md). Everything is generated by reproducible pipelines in tools/.
- **Factions**: Meridian Command vs the Jackal Front.

## Repository map
- `data/` — the complete original game dataset (INI, maps, art, audio)
- `tools/` — asset pipelines: Blender model builds, texture/map/audio
  generators, web staging
- `web/` — the browser shell
- `docs/` — decisions, engine notes, roadmap

## Building
See docs/engine-notes.md for the native and wasm build recipes, and
`git submodule update --init --recursive` after cloning.
